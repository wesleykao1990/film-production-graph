## License handling rule

- Reuse ideas freely at the architectural level.
- Reuse code, prompts, schemas, or assets only after verifying the exact current license and attribution obligations.
- Treat repositories without a detected license as not reusable by default.
- Treat non-commercial, ShareAlike, or source-available licenses as requiring product/legal review.
- Record third-party code and asset provenance in the repository and release manifest.
