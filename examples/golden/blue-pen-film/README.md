# Blue Pen Film

This directory is the real, manual/nightly acceptance project. It is intentionally separate from `blue-pen-fixture`.

Rules:

- real provider runs and human selections are allowed;
- outputs are not byte-stable and do not run on every PR;
- provider policy and rights records must reflect actual services/assets;
- unknown manual metadata remains unknown;
- the film must pass the locked Delivery Specification;
- subtitles, human AI-use disclosure, and provenance sidecar are required;
- generated music is disabled unless an explicit rights-cleared project decision enables it.

Start from the narrative files copied from the fixture, then replace all fixture-only rights/provider/audio data with real project records.
